# Icon sources for Folder Icon Studio

## Bundled by default

The app ships with the **New Icons** pack from this project (~900 Windows-style `.ico` files), organized by folder:

| Category | Examples |
|----------|----------|
| applications | Office, Edge, settings apps |
| devices | Hardware peripherals |
| emblems | Badges and marks |
| Folders | Colored folder icons |
| folders 2 | More folder styles |
| Mono | Monochrome set |
| objects | Misc objects |
| Random | Assorted |
| System | Windows system icons |

Stored in: `%USERPROFILE%\Pictures\Folder Icons\_Bundled\<category>\`

## Add your own

Use **Import image** or drop files into `My Icons\`. The app scans all subfolders recursively.

| Library | License | Notes |
|---------|---------|-------|
| [Phosphor Icons](https://phosphoricons.com/) | MIT | Large set |
| [Lucide](https://lucide.dev/) | ISC | Clean line icons |
| [Bootstrap Icons](https://icons.getbootstrap.com/) | MIT | Web-friendly |
| [Heroicons](https://heroicons.com/) | MIT | Tailwind team |

**Tip:** Use `.ico` files with 256×256 frames for best results on Windows folders.
